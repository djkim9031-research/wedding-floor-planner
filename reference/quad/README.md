# The Quad Conference Center — reference photos

The planner models The Quad Conference Center (formerly Quadrus), 2400 Sand Hill Rd,
Menlo Park. These five photos were taken at dusk (~15 min after sunset) and are the
calibration targets for the photoreal renders (Photo mode and Blender Cycles).

| File | View |
|---|---|
| `01-deck-rail-view.jpg` | Tree Deck railing looking NE over the parking lot to the Bay |
| `02-hall-entry.jpg` | Hall interior toward the south entry doors |
| `03-covered-deck-oak.jpg` | Covered deck bay and the deck oak |
| `04-oak-trunks-deck.jpg` | Oak trunks rising through the deck boards |
| `05-hall-window-wall.jpg` | Hall interior toward the deck window wall |

`cameras.json` holds the fitted camera for each photo (position in inches, yaw/pitch
in degrees, vertical FOV) so renders can be compared side by side.
